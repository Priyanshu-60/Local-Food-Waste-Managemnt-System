# **🍴Food Donation Management System**

A Streamlit-based web application designed to manage and analyze food donations efficiently.
The system enables Providers to donate food, Receivers to claim it, and administrators to track, manage, and generate insights through reports.

----

🚀**Features:**
🔹 CRUD Operations
- Manage Providers 👨‍🌾
- Manage Receivers 🏢
- Manage Food Listings 🥗
- Manage Claims 📦

Each module supports CRUDE Operations

🔹 Reports & Analytics 📊
- Providers & Receivers per city
- Top contributing provider type
- Top receivers by claims
- Total food available
- City with highest listings
- Most common food types
- Claim status distribution
- Monthly donation trends

----

🛠️**Tech Stack:**
- Frontend/UI: Streamlit
- Backend: Python
- Database: MySQL
- Libraries: Pandas

Dependencies are listed in 👉 requirements.txt

----

📂**Project Structure:**

├── app.py              # Main Streamlit application
├── db.py               # Database connection setup
├── reports.py          # SQL queries & analytics logic
├── requirements.txt    # Dependencies
├── *.csv / *.xlsx      # Dataset files
├── *.sql               # Database schema

----

📊**Key Highlights:**
- Interactive dashboard with real-time database operations
- Efficient SQL-based analytics
- Clean UI with custom styling in Streamlit
- Modular code structure for scalability

----

🎯**Use Case:**

This system helps:

- Reduce food wastage 🍽️
- Connect donors with receivers 🤝
- Track donations and claims efficiently
- Provide data-driven insights for decision-making
